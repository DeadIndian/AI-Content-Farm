      The way this studio works

      01

      Cloud intelligence, a lightweight workspace

      Gemini can write scripts, voice your presenters, and transcribe footage in the cloud. No local AI model is needed. Your computer handles video assembly, one export at a time.

      02

      Pick the voice for each video

      Use Gemini cloud voice for natural narration, or the lightweight demo voice to try the workflow without voice API calls. Manual scripts and curated demos remain available. Credentials stay in the server environment.

      03

      Keep creative control

      Review generated claims and source notes, edit each scene, then render. Planning steps are visible in every draft. Nothing publishes to YouTube automatically.
